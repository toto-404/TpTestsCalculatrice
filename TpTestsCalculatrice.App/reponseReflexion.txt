1. Quelle est la différence entre un test manuel et un test unitaire ?

- Test manuel : on exécute et vérifie à la main (ex : programme qui affiche 5 et 5).
- Test unitaire : code automatisé vérifie un comportement précis (ex : Assert.AreEqual(5, calc.Addition(2,3))).

2. Pourquoi place-t-on les tests dans un projet séparé ?

- Isolation : pas de dépendances de production dans le code métier.
- Exécution facile et clarté pour maintenir la qualité.

3. Pourquoi faut-il tester plusieurs cas pour une même méthode ?

- Couvrir valeurs normales, limites, erreurs (division par zéro, négatifs, zéro).
- Éviter les bugs cachés et les régressions.

4. Que signifient les trois étapes de la méthode AAA ?

- Arrange : préparer le contexte (Calculatrice calc = new Calculatrice()).
- Act : exécuter la méthode (var r = calc.Division(10,2)).
- Assert : vérifier le résultat (Assert.AreEqual(5, r)).
